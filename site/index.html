Why does an agent need governance?

AI coding agents write files directly, with your permissions, at machine speed. When they get it wrong — or when you simply want to know what they did — the change is already on disk, with no decision point and no record.

TANUQ turns that one-way write into a governed decision: the agent proposes, TANUQ classifies the risk deterministically, you approve what is risky, and everything is verified and recorded.

How it works

  1. Agent Your AI agent wants to change a file.
  2. Proposal The change is submitted as a fingerprint-bound proposal — never a direct write.
  3. Risk A deterministic risk engine classifies it from system signals: path, action, size, content, location.
  4. Approval HIGH/CRITICAL changes wait for your explicit, single-use, fingerprint-bound approval.
  5. Execute Approved changes are applied as governed mutations — atomically, in scope only.
  6. Verify Compilation and tests must pass; a failed verification rolls the change back automatically.
  7. Evidence Every decision and outcome is recorded in a tamper-evident chain.

TRY TANUQ

A governed demo runs locally on your machine, in a disposable workspace, using only test files. No production files are touched and no secrets are required. The workspace is cleaned up automatically when the demo finishes.

Prerequisite: Python 3.12+ and git. TANUQ runs locally — the demo sends nothing to any server.

Windows (PowerShell)

git clone https://github.com/khalikinisoran-jpg/olay-kaynak-platformu.git tanuq-demo
cd tanuq-demo
pip install -e .
powershell -ExecutionPolicy Bypass -File site\try\try_tanuq.ps1

Linux / macOS (bash)

git clone https://github.com/khalikinisoran-jpg/olay-kaynak-platformu.git tanuq-demo
cd tanuq-demo
pip install -e .
bash site/try/try_tanuq.sh

The demo walks the real governed pipeline: proposal → risk → approval → governed mutation → verification → evidence — and finishes with a cleanup and an OVERALL PASS summary.

Honest limits

  • TANUQ governs changes proposed through Tanuq only — an agent writing files directly (outside Tanuq) is not intercepted.
  • No OS sandbox and no network enforcement.
  • Evidence is tamper-evident (detectable), not tamper-proof.
