PROBLEM

AI agent bir değişiklik yapmak istediğinde son karar kimde?

AI coding agent'lar kod yazabilir, dosya değiştirebilir ve insan müdahalesi olmadan makine hızıyla çalışabilir. Bu hız değerli — ama her değişiklik kontrol gerektirmez. Kritik olan: hangilerinin kontrol gerektirdiğine kim karar veriyor?

AI agent bir değişikliği doğrudan diske uyguladığında, insanın karar vereceği an değişiklikten önce değil sonra olabilir. O noktada geri dönüş maliyetli ve zaman alıcıdır.

NASIL ÇALIŞIR

Altı adımda çalışır.

Propose → Risk → Approval → Execute → Verify → Evidence. Her adım görünür; yetki bir sonraki adıma taşınmaz.

1Öneri

Agent değişikliği doğrudan diske yazmaz; TANUQ'a öneri olarak gönderir. Önerinin hedef dosyası ve içeriği uygulama öncesinde görünür hale gelir.

2Değerlendirme

Her öneri sınıflandırılır: uygun değişiklikler uygulanabilir, riskli değişiklikler onayınızı bekler.

3Onay

Riskli değişikliklerde karar sizde kalır. Onay verilmeden ilgili değişiklik uygulanmaz.

4Uygulama

Onaylı değişiklikler atomik olarak uygulanır. Kapsam dışına çıkmaz.

5Doğrulama

Uygulama sonrası derleme ve testler koşar. Başarısızlık durumunda değişiklik geri alınır.

6Kayıt

Her öneri, onay ve sonuç kayıt altına alınır. Kayıt zincirindeki sonradan yapılan değişiklikler tespit edilebilir.

DEĞER

Size ne kazandırır?

CONTROL

Riskli değişikliklerde karar sizde kalır. İlgili değişiklik, sizin onayınız olmadan uygulanmaz.

VISIBILITY

Değişiklik uygulamadan önce görünür hale gelir: hangi dosya, hangi işlem, hangi içerik farkı.

VERIFICATION

Uygulama sonrası derleme ve testler çalıştırılır; sonuç doğrulanır.

EVIDENCE

Her öneri, onay ve sonuç kayıt altına alınır. Kayıt zincirindeki sonradan yapılan değişiklikler tespit edilebilir.

LOCAL TRY

Kendi makinenizde gerçek runtime'ı çalıştırın.

Tarayıcıdaki demo recorded playback'tir. Gerçek TANUQ runtime'ını kendi bilgisayarınızda çalıştırırsınız: geçici çalışma klasöründe yönetilen akışı uçtan uca koşar; bitince kendini temizler.

Windows (PowerShell)

git clone https://github.com/khalikinisoran-jpg/olay-kaynak-platformu.git tanuq-demo
cd tanuq-demo
pip install -e .
powershell -ExecutionPolicy Bypass -File site\try\try_tanuq.ps1

Linux / macOS (bash)

git clone https://github.com/khalikinisoran-jpg/olay-kaynak-platformu.git tanuq-demo
cd tanuq-demo
pip install -e .
bash site/try/try_tanuq.sh

Önkoşul: Python 3.12+ ve git. Demo tamamen yerel çalışır; hiçbir veri sunucuya gönderilmez.

Sonraki adım: tanuq init ile kendi projenizi koruyun, tanuq ui ile dashboard'u açın.
